# Practice 3 – Functions and OOP

## Description

This practice contains examples of Python Functions and Object-Oriented Programming (OOP).

### Topics Covered

#### Functions

* Basic functions
* Function arguments
* Return values
* *args and **kwargs

#### Lambda

* Basic lambda expressions
* Lambda with map()
* Lambda with filter()
* Lambda with sorted()

#### Classes

* Class definition
* **init**() method
* Class methods
* Class variables

#### Inheritance

* Basic inheritance
* super() function
* Method overriding
* Multiple inheritance

## Goal

The goal of this practice is to understand how functions work, how lambda expressions simplify code, how classes and objects are created, and how inheritance is used in object-oriented programming.
