# Practice 6: Python File Handling and Built-in Functions

This practice contains examples about file handling, directory management, and Python built-in functions.

## File handling

Files are inside `file_handling` folder.

Examples:
- create and write text files
- read files with `read()`, `readline()`, `readlines()`
- append new lines
- copy files with `shutil`
- delete files safely with `Path.unlink()`

## Directory management

Files are inside `directory_management` folder.

Examples:
- create folders with `mkdir()`
- create nested folders with `parents=True`
- list files with `os.listdir()`
- find files by extension with `glob()`
- copy and move files with `shutil`

## Built-in functions

Files are inside `builtin_functions` folder.

Examples:
- `map()`
- `filter()`
- `reduce()`
- `enumerate()`
- `zip()`
- `len()`, `sum()`, `min()`, `max()`, `sorted()`
- type conversion: `int()`, `float()`

## How to run

Open terminal inside Practice6 folder and run:

```bash
python file_handling/write_files.py
python file_handling/read_files.py
python file_handling/append_files.py
python file_handling/copy_delete_files.py
python directory_management/create_list_dirs.py
python directory_management/move_files.py
python builtin_functions/map_filter_reduce.py
python builtin_functions/enumerate_zip_examples.py
```
